# MOROAI 1 — OPEN SOURCE RESEARCH PROTOCOL

## PHASE 1 — MOROAI INSPECTION

- inspect repository
- inspect relevant files
- inspect dependencies
- inspect tests
- inspect current architecture
- inspect git status/history

## PHASE 2 — EXTERNAL RESEARCH

- search GitHub
- identify multiple relevant projects
- inspect actual implementation
- inspect interfaces
- inspect recent project direction
- inspect license

## PHASE 5 — IMPLEMENTATION

Only after research and decision:

- create plan
- implement smallest safe change
- preserve existing functionality
- add/update tests
- verify
- inspect git diff

## PHASE 6 — KNOWLEDGE UPDATE

Update:

- MOROAI_KNOWLEDGE_INDEX.md
- relevant research document
- architecture decision record
- repository snapshot when appropriate

## PHASE 7 — FINAL VERIFICATION

Report:

- what changed
- why
- open-source projects inspected
- files changed
- tests run
- verification result
- remaining risks
- next step

---

# NON-NEGOTIABLE RULE

Open-source code is research material.

Do not blindly copy implementation.

Prefer understanding the underlying design and adapting it cleanly to MOROAI.

Always check the license before reusing code.
